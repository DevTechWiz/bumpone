# Bumped.lol — Project Overview

## Product

Bumped.lol is a living visual arena where people and profiles compete for position, physically bump each other down the wall, build a public ranking history, and share their biggest climbs.

The core concept is:

> Buy a position. Bump everyone below you. Watch the wall move.

---

## Product Positioning

Bumped.lol is NOT merely another paid leaderboard.

It is:

- a living visual arena
- a competitive social experience
- a public ranking journey
- a shareable moment generator
- a game of position and status

The core product loop:

Enter → Climb → Bump → Watch the wall move → Build ranking history → Share the moment → Come back and defend/climb your position

---

## The Bumped Wall

The primary experience is a dynamic visual wall where rank controls visual prominence.

The wall is NOT a conventional leaderboard. It is a visually hierarchical grid where:

- #1 receives a dramatically large tile
- #2–#10 receive medium tiles
- #11–#100 receive smaller tiles
- Tiles shift positions when someone bumps into a higher position
- The wall visibly rearranges after each purchase

When someone bumps into a higher position, the wall visibly rearranges and tiles shift positions.

The visual wall is core product identity, not UI decoration.

---

## Core Experience

A visitor sees a visually striking wall of ranked images.

Higher positions receive dramatically larger visual areas.

Lower positions receive smaller visual areas.

The wall is continuously changing as users make purchases.

When a new purchase occurs:

1. The buyer's active value is increased via top-up.
2. They enter at the position where their new active value strictly exceeds the target.
3. Existing users with lower active values move down.
4. The wall visibly rearranges.
5. The ranking remains continuous.
6. If someone moves beyond #100, they disappear from the main wall.
7. Their profile remains in the system.
8. A bump event appears in the live feed.
9. The buyer sees a post-bump result screen.
10. A shareable bump moment is generated.

## Post-Bump Result

After a successful purchase, the impact is explicitly shown:

You're now #12

You just moved above 38 profiles.

Shows:

- Previous rank
- New rank
- Number of profiles displaced
- New active value
- Profiles that were pushed down

The result feels like an event rather than a generic payment-success screen.

## Categories

Users belong to a category. Each category has its own derived ranking.

Example:

Global:

#1   A  active value $700
#2   B  active value $250
#3   C  active value $100

AI category:

#1   A  active value $700
#2   C  active value $100

Apps category:

#1   B  active value $250

The category rank is the user's position among profiles in that category, sorted by active value descending.

Category rankings use the same `current_active_value`. No separate payments. No separate pricing.

The global board is the default view. Users can filter by category to see category-specific rankings.
