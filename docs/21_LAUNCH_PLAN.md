# Bumped.lol — Launch Plan

## Prelaunch

Create:

- landing page
- short demo video
- social accounts
- launch screenshots
- explanation video

---

# Initial Board

Do not launch with an empty-looking board.

Seed the visual experience with clearly labeled demo/placeholder profiles if appropriate.

Do not represent fake purchases as real purchases.

---

# Launch Message

The product should be demonstrated rather than explained.

Example concept:

"I built a website where you pay to climb a live internet leaderboard."

Then show:

payment

↓

bump

↓

profiles moving

↓

new position

# Viral Loop

User purchases.

↓

User shares their position.

↓

Friend visits.

↓

Friend sees live board.

↓

Friend wants a higher position.

↓

Friend purchases.

↓

Original user may get bumped.

↓

Original user returns.

---

# Key Marketing Asset

The bump animation.

It should be instantly understandable in a 5–10 second video.

---

# Mandatory Pre-Launch Checklist

Do not launch real-money transactions until the payment-provider and applicable legal/business requirements have been reviewed for the actual operating jurisdiction.

### Legal / Business

* Terms of Service
* Privacy Policy
* Refund policy
* Content policy
* Reporting process
* Copyright/trademark process
* Appropriate business/contact disclosures
* Tax/business requirements
* Data-protection requirements

### Payment

* Payment provider approval
* Production account
* Webhook verification
* Refund workflow
* Chargeback workflow
* Provider restrictions reviewed

### Infrastructure

* Domain registered and renewal controlled
* DNS documented
* Production database backups
* Storage backups
* Secrets management
* Admin recovery access
* Monitoring
* Error tracking

### Security

* Authentication
* authorization
* RLS/access rules
* rate limits
* webhook signature verification
* input validation
* image validation
* URL validation
* abuse controls

### Moderation

* report system
* admin review
* profile suspension
* profile removal/hiding
* audit log
